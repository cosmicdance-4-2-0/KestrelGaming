# Development log

This file is the engineering chronology for developers, maintainers and agents.
User-facing release notes are in [Changelog.md](Changelog.md).

Add one entry for each meaningful checkpoint, in date order, oldest first. Use this format:

```text
## YYYY-MM-DD — Scope

- Result: what was implemented or decided.
- Reference: commit, pull request or decision.
- Verification: checks that ran, their results and their limits.
- Open: significant unresolved work.
```

Do not record every agent action. Link to full reports instead of copying them.
When later evidence changes a conclusion, add a dated amendment. Do not rewrite the earlier entry.
