## Registration policy

A branch and a profile document do not authenticate a runtime agent identity.
Shared contract and knowledge are usable without an individual agent profile.

When continuity for an established agent is useful, add a lowercase agent
directory, an `INDEX.md`, and scoped records from the
[memory template](../../kestrel/templates/MEMORY.md).
Link the agent's index here. Record identity and preferences only when supplied
or explicitly established; do not invent personal history.

Agent-specific means scoped, **not private**. Everyone who can read the
repository can read these files. Project facts and handoffs still belong in
their project scope.
