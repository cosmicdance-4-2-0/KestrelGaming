# CosmicDance HollowLumen — Axiom project profile

## Summary

The repository [cosmicdance-4-2-0/hollowlumen](https://github.com/cosmicdance-4-2-0/hollowlumen) is the product-design and branding fork of parent `valubester/hollowlumen`, not the executable project. Its 2026-11-05 main head `4736ab3bb7fa9cbc316043093a02d9f313c52a51` contains 13 Markdown files including README and four original SVG brand artifacts; it has no application source, package manifest, tests or CI workflow. Two PRs are merged.

The implementation fork [Kisuul/hollowlumen](https://github.com/Kisuul/hollowlumen) shares exact commit ancestor `ac0317e250bef11c1f12abebe7be023aa41ecb47` and has a React/Vite playable prototype. Its inspected main revision `c00e15e7af5ba028584363f4be6151a373b084ec` implements single-Pip economy, appearance and solar, not multi-critter identity or native widget.

Key design docs: `docs/PRODUCT_SPEC.md` (earlier creature-first narrow scope), `docs/PLAYABLE_GAME_HYPOTHESIS.md` (current integrated game experiment), `docs/CLIENT_REVIEW.md` (unresolved decisions), `docs/TEAM_B_SYNCHRONIZATION_BRIEF.md` (B-01 analysis-only handoff), `docs/DESIGN_LANGUAGE.md` and `docs/BRAND_PROTOTYPE.md` (unapproved Lavender & Loop style and SVG brand kit).

No current client signoff of this fork's complete product direction, brand or mechanics is evidenced in source or PR reviews. Permission to write the Axiom memory branch is separate from any permission to change either HollowLumen repository.
