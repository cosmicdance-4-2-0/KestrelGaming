Are guard order, state retention, slot reuse and repeated-call outcomes deterministic? Check both cross-principal retry and ordinary owner recovery. 3. **Recovery invariants.** Successful restore recovers local unsent text; server body/revision and cached base remain unchanged. Check this against conflict, no-cache, user-switch, denied and offline paths. Distinguish required confidentiality from explicitly excluded physical/OS compromise.
